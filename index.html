取色鸭

简单、轻快的中文取色工具

Version 2.0.10 取色鸭官网 小红书主页

需要"屏幕录制"权限

取色需要读取屏幕画面，macOS 要求你手动授权一次。

关键：授权后必须完全退出再重新打开取色鸭，权限才会生效。只关闭窗口不算——窗口关闭后程序仍在托盘里运行。

  1. 点击「打开系统设置」，在「隐私与安全性 → 屏幕录制与系统音频」里打开「取色鸭」的开关。（"系统音频"只是这个设置页面的名字，取色鸭不会录制任何音频。）
  2. 你似乎是直接从 DMG 里运行的：请先把取色鸭拖进「应用程序」文件夹再打开，否则授权可能无法生效。
  3. 回到这里，点击「重启取色鸭」。
更新版本后若取色失效：请先在系统设置里移除「取色鸭」，再重新添加屏幕录制权限；请使用 GitHub Release 的正式版本。
