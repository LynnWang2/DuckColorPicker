FAQ

几个常见问题。

支持哪些系统？

目前支持 Windows 与 macOS；macOS 发布 Apple Silicon + Intel 通用版本，Windows 提供 64 位安装包。

macOS 为什么需要屏幕录制权限？

屏幕取色需要读取像素颜色，因此首次使用会请求“屏幕与系统音频录制”权限。

快捷键和复制格式能修改吗？

可以。快捷键、主题、复制格式、开机启动等都可以在主界面中直接设置。

项目开源吗？

是，源代码与版本发布都托管在 GitHub。
